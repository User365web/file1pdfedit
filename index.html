Guide

Pick the right tool

Use Merge PDF to join files and Split PDF to extract pages. Use Delete PDF Pages to remove pages you do not need, and Rotate PDF when a scan came out sideways. Image to PDF turns photos and screenshots into a document, while PDF to JPG goes the other way.

Keep file size under control

Large PDFs often fail to send by email or upload to forms. Run Compress PDF in Strong mode for scans and photo-heavy files. If the result is still too big, split the document and send it in parts.

Your files stay private

All tools run locally in your browser with JavaScript. Your documents are not uploaded, so contracts, IDs and invoices never leave your device. Close the tab and nothing is kept.

Works on phones and computers

File1pdfedit works in current versions of Chrome, Edge, Firefox and Safari on desktop and mobile. Very large files need more memory, so on a phone try files under about 100 MB.

FAQ

Is File1pdfedit free?

Yes. Every tool is free with no sign-up, no watermark and no daily limit. The site is paid for by advertising.

Are my PDF files uploaded anywhere?

No. Files are processed inside your browser and never sent to a server.

Which tools are available?

Compress PDF, Image to PDF, Merge PDF, Split PDF, Rotate PDF, PDF Page Counter, PDF Info, Delete PDF Pages, PDF to JPG, Add Page Numbers, Add Watermark and Edit PDF Metadata.

Can I use it on my phone?

Yes. The site works on modern mobile browsers. Large files may be slow on older phones.

Why is my compressed PDF not smaller?

Some PDFs are already optimized. Try Strong mode with the Smallest size option, which converts pages to compressed images.

Can I open password-protected PDFs?

Tools that rewrite the file need an unprotected PDF. Remove the password first in the program that created the file.
