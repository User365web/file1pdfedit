Rotate PDF

Fix pages that are sideways or upside down and save the corrected PDF.

🔄Drop a PDF here to rotate itChoose fileor drag and drop. PDF files only

    Private: your files are processed on your device and never uploaded.

    How to use Rotate PDF

    1. Add your PDFDrop the PDF onto the box.
    2. Choose rotationPick the angle and, if needed, the pages to rotate.
    3. DownloadPress Rotate PDF and save the fixed file.

    Rotate PDF guide and tips

    Leave the pages box empty to rotate the whole document. To rotate only some pages, type them like 2, 4-6.

    Rotation is saved in the file itself, so it looks right in every PDF viewer, on phones and when printing.

    Run the tool again if you need different pages turned by different amounts.

    Rotate PDF FAQ

    Can I rotate only one page?

    Yes. Type the page number in the Pages box, for example 3, and only that page will be rotated.

    Is the rotation permanent?

    Yes. The new file stores the rotation, so it opens the right way up everywhere.

    Are my files uploaded to a server?

    No. Everything happens inside your browser on your own device. Your PDFs and images are never sent to our servers, so your documents stay private.

    Is this tool really free?

    Yes. It is free to use with no sign-up, no watermark and no daily limit. The site is supported by advertising.
